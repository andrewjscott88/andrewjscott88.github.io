## Open-Source Projects

- **[Insight](https://github.com/andrewjscott88/insight)** (MIT licence): a self-hosted threat-intelligence workspace for defenders. It pulls public advisories from CISA (Known Exploited Vulnerabilities and CSAF advisories), SANS ISC and the UK NCSC, extracts CVEs and indicators with the source text as evidence, and applies TLP sharing labels. Built with Python, FastAPI, NiceGUI and SQLAlchemy on SQLite or PostgreSQL.
